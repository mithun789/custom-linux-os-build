USAGE OPTIONS
═══════════════════════════════════════════════════════════════

OPTION 1: Test in QEMU (Virtual Machine)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Install QEMU first:
$ sudo apt install qemu-system-x86

Run your OS in QEMU:
$ cd ~/buildroot/output/images
$ qemu-system-x86_64 \
    -drive file=disk.img,format=raw \
    -m 2G \
    -enable-kvm \
    -cpu host \
    -smp 4

Or with network:
$ qemu-system-x86_64 \
    -drive file=disk.img,format=raw \
    -m 2G \
    -netdev user,id=net0 \
    -device e1000,netdev=net0

OPTION 2: Create Bootable USB Drive
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

⚠️  WARNING: This will ERASE all data on the USB drive!

1. Insert USB drive and identify it:
   $ lsblk

2. Unmount if mounted:
   $ sudo umount /dev/sdX*

3. Write the disk image:
   $ sudo dd if=~/buildroot/output/images/disk.img \
            of=/dev/sdX \
            bs=4M \
            status=progress \
            conv=fsync

   Replace /dev/sdX with your USB device (e.g., /dev/sdb)

4. Sync and eject:
   $ sync
   $ sudo eject /dev/sdX

5. Boot from USB:
   - Insert USB into target computer
   - Access BIOS/UEFI (usually F2, F12, DEL, or ESC)
   - Select USB drive as boot device
   - Boot into your custom OS!

OPTION 3: Deploy to Physical Hard Drive
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

⚠️  WARNING: This will ERASE the target drive!

Same process as USB, but use target drive:
$ sudo dd if=~/buildroot/output/images/disk.img \
         of=/dev/sda \
         bs=4M \
         status=progress \
         conv=fsync

OPTION 4: Manual Kernel Boot (Advanced)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

$ qemu-system-x86_64 \
    -kernel ~/buildroot/output/images/bzImage \
    -drive file=~/buildroot/output/images/rootfs.ext2,format=raw \
    -append "root=/dev/sda console=ttyS0" \
    -nographic
